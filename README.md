
# ClipBoardBinder

A Windows clipboard utility that automatically merges the contents of multiple copied text files for easy pasting.

## Features
- Automatically merges multiple copied text files
- Option to display file names
- Dark/Light theme support
- Multi-language support (Korean, English, Japanese, Spanish)
- Simple and intuitive UI


## How to Use
1. Download and run the latest release.
2. Select and copy (Ctrl+C) multiple text files in File Explorer
3. Paste (Ctrl+V) anywhere to insert the merged text contents
